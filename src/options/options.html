Profils de brief

Collecte

Mise en place — 1. Crée une page Notion vide dédiée (ex. « Notebooker — dépôt ») dans l'espace Opale ; connecte-la à Notebooker (Réglages › Notion) et donne à la routine l'accès Notion à cette page. 2. Dans Claude Code › Routines : crée la routine avec le prompt copié et les connecteurs Gmail, Agenda, Notion ; ajoute un déclencheur API et génère le jeton. 3. Colle ici l'URL et le jeton, enregistre. Au déclenchement (heure du profil ou « Lancer »), Notebooker appelle la routine, attend son dépôt dans la page puis génère le podcast.
Le jeton ne sert qu'à déclencher cette routine (aucun accès en lecture) ; il n'est envoyé qu'à api.anthropic.com.
Aucun connecteur requis : Claude Cowork agrège Gmail, Agenda et Notion ; l'extension lit le dossier, calcule le diff jour après jour (nouveau / modifié / sans nouveauté / résolu) et génère le podcast. L'heure ci-dessus sert de filet de sécurité.

Dossier local · Claude Cowork

Pour les profils en mode « Dossier local » : une tâche planifiée Claude Cowork écrit le brief dans ce dossier, l'extension le lit et génère le podcast.

Vérification de l'accès aux fichiers…
Paramètres du prompt Cowork (bases Notion, GitHub)
Sans dépôt listé, Cowork s'appuie sur les PR GitHub synchronisées dans les Tech tasks (champ « GitHub pull requests » et « Merge »).
Mise en place — 1. chrome://extensions › Notebooker › Détails › activer « Autoriser l'accès aux URL de fichier ». 2. Crée le dossier, puis dans Claude (Cowork) donne-lui accès à ce dossier et crée une tâche planifiée (ex. 7 h 00, jours ouvrés) avec le prompt copié. 3. Ici : profil en mode « Dossier local », actif, surveillance activée. Le prompt contient tes exclusions de conformité.

Notion

Un accès par workspace. Jeton d'API si tu peux créer une connexion interne ; sinon OAuth (aucune autorisation d'admin requise : tu choisis les pages partagées lors de la connexion).

Configurer OAuth dans Notion — Outils pour les développeur·euses › Connexions › Nouvelle connexion › OAuth, puis colle cette URI de redirection :
Récupère ensuite le Client ID et le secret client de la connexion et colle-les ci-dessus. Ils restent stockés localement dans Chrome (jamais dans le code de l'extension).
